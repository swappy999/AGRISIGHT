# 1. CURRENT PRODUCT DIRECTION

AgriSight is a farmer-focused AI agriculture platform.

For the current SIH prototype:

- Gemini AI is the active AI inference engine.
- Edge AI is **NOT required now** and must not block delivery.
- The application is **ONLINE-ONLY for this sprint**.
- Offline mode, SQLite sync, advanced edge inference, LoRa and similar work are postponed.
- Hardware/IoT components are postponed until the software is stable.
- Desktop/web is the first target.
- Android/Capacitor is the second target.
- Hardware is the final phase.

The goal is a polished, working prototype rather than an over-engineered system.

# 4. SCAN AI UX

The crop scanning flow must be one of the strongest parts of the application.

Flow:

```text
Scan Crop
   ↓
Camera / Upload
   ↓
Crop/Non-Crop Validation
   ↓
Gemini Vision
   ↓
Disease / Pest / Nutrition / Water / Risk
   ↓
Concise Result
```

## Critical rule

If the uploaded image is not a plant/crop:

```text
status = NON_CROP
```

Do NOT guess:

```text
Tomato
Healthy Plant
Unknown crop → Tomato
```

Do not use fake confidence.

## Result page

Do not display a giant wall of AI text.

Show compact cards/buttons:

```text
Crop
Disease
Pest
Nutrition
Water
IPM
Compare
```

Each opens its own detail view.

Main result should contain:

```text
Detected crop
Main issue
Risk level
Confidence (only if actually provided/reliably calculated)
Short explanation
Immediate action
```

Then:

```text
[ Disease Details ]
[ Water Advice ]
[ Nutrition ]
[ IPM ]
[ Compare ]
```

# 6. GEMINI RESPONSE CONTRACT

Use structured responses wherever possible.

Example:

```json
{
  "status": "success",
  "crop": "Rice",
  "diagnosis": "Possible bacterial leaf blight",
  "confidence": 0.87,
  "severity": "medium",
  "summary": "Symptoms may indicate bacterial leaf blight.",
  "actions": [
    "Inspect nearby plants.",
    "Avoid excessive nitrogen application.",
    "Monitor spread over the next few days."
  ],
  "water_advice": "...",
  "nutrition_advice": "...",
  "ipm_advice": "..."
}
```

The exact schema should be adapted to the existing backend rather than duplicated.

If Gemini cannot confidently determine a diagnosis:

```text
status = uncertain
```

and ask for a clearer image or recommend field inspection.

Never fabricate certainty.
