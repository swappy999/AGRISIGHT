# AgriSight — Edge AI Phase 1: Web Crop / Non-Crop Validator

## NON-NEGOTIABLE
Implement **ONLY Phase 1**.

Do not implement:
- Disease Edge AI
- Pest Edge AI
- Nutrition Edge AI
- Edge AI Assistant
- IoT
- ESP32
- Android native Edge AI

Process:

```text
Inspect → Implement → Test → Fix → Report → STOP
```

Wait for explicit approval before Phase 2.

---

## Objective

Add a real **browser-local Edge AI validator** to the existing AgriSight Scan flow.

It answers only:

> Is this image a crop/plant suitable for agricultural analysis?

This must prevent the previous false-positive problem where unrelated images became:

```text
Tomato
Healthy
95%
```

---

## Target Flow

```text
Camera / Upload
↓
Image Quality Check
↓
LOCAL EDGE AI
↓
CROP / NON-CROP / UNCERTAIN
├── NON-CROP → Reject immediately
├── UNCERTAIN → Ask for clearer image
└── CROP → Continue existing AgriSight scan pipeline
```

## 2. Dataset

Build a reproducible dataset using legitimate/licensed sources where permitted, including suitable agricultural sources such as:

- PlantVillage
- PlantDoc

Add an AgriSight `non-crop` dataset containing:

- people/faces
- selfies
- animals
- cars
- phones
- laptops
- rooms/buildings
- documents
- screenshots
- random objects
- unrelated scenery

Required classes:

```text
CROP_OR_PLANT
NON_CROP
```

Optional internal quality labels may include:

```text
BLURRY
LOW_LIGHT
UNKNOWN
```

Do not put raw training data in the production web assets.

## 4. Data Preparation

Create reproducible preprocessing:

- validate images
- remove corrupted images
- resize consistently
- normalize consistently
- deduplicate where practical
- preserve labels

Produce:

```text
Total images
Crop images
Non-crop images
Train
Validation
Test
```

Use a proper held-out test set.

Suggested starting split:

```text
70% train
15% validation
15% test
```

Avoid train/test leakage.

## 5. Model

Use a lightweight image classifier suitable for browser inference.

Evaluate lightweight candidates such as:

- MobileNet-style model
- compact CNN
- another small vision architecture appropriate to the actual dataset

Optimize for:

```text
Accuracy
Precision
Recall
F1
Model Size
Inference Speed
Browser Memory
```

Do not choose a huge model just for raw accuracy.

## 7. Uncertainty

Support:

```text
CROP
NON_CROP
UNCERTAIN
```

Use a configurable confidence threshold.

Do not force a prediction when confidence is too low.

Example:

```text
confidence < threshold
→ UNCERTAIN
```

Do not scatter hard-coded thresholds through the codebase.

---

## 8. Browser Runtime

Integrate the model locally in the website using an appropriate browser inference runtime, evaluating options such as:

- ONNX Runtime Web
- TensorFlow.js

Choose based on the exported model and the existing project.

Target:

```text
Image
↓
Browser
↓
Local Model
↓
Prediction
```

The validation decision must not require a server call.

---

## 9. Model Loading

Do not load the model on every scan.

Use:

```text
First scan
↓
Load model
↓
Cache in memory
↓
Reuse
```

Show:

```text
Preparing scan AI...
```

Do not block the entire application.

If model loading fails:

```text
Local scan AI is unavailable.

[ Retry ]

You can use standard online analysis
when a connection is available.
```

Never fake a result.

---

## 10. Image Quality

Before local inference verify:

- image exists
- file is readable
- dimensions > 0
- reasonable resolution
- not obviously corrupted

If clearly unusable:

```text
The image is too unclear.

Please take a clearer photo.
```

This is separate from crop/non-crop classification.


## 16. Remove Dangerous Defaults

Search for and remove patterns such as:

```javascript
result?.crop || "Tomato"
result?.diagnosis || "Healthy Plant"
result?.confidence || 95
```

Frontend must never invent results.

Use explicit states:

```text
CROP
NON_CROP
UNCERTAIN
ERROR
```

---

## 17. Stable Type

Create one internal result type, adapted to the existing TypeScript architecture:

```ts
type EdgeValidationResult = {
  decision: "CROP" | "NON_CROP" | "UNCERTAIN";
  confidence: number;
  modelVersion: string;
  inferenceMs: number;
};
```

Do not duplicate this type across files.
